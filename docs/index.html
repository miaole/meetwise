项目展示 · 不是在线应用服务

真实经历 → 自适应面试 → 可复盘成长

知面是一个以面试训练为中心的 AI 求职准备平台。面试官是自适应 Agent，不是套题模板：按你的真实经历出题、追问，并把练习沉淀成可以回头看的反馈与成长记录。

写给求职者、转岗者和要练深度技术面的开发者；也写给想看承重工程的同行——Postgres 检查点、prove 门禁、隐私诚实边界都在仓库里。

查看源码 阅读 README GitHub Pages 只做导航与展示，不启动本地数据面服务。
Differentiators

这不是调一下模型接口的 demo

承重件在编排、状态和验证，不在聊天外壳。下面四条是仓库里已经写明、可以用门禁核对的差异。

01

自适应面试 Agent

四张 LangGraph 图按输入分流。模型输出先过 schema、再过业务校验，才进入业务逻辑；不幻觉简历事实，也不裸解析 JSON。

02

可恢复的长会话

检查点落在 Postgres，等待用户输入是持久化状态，没有内存 session map。多实例可续答；前端消费业务事件，不消费模型 token。

03

Prove 门禁

db / runtime / graph / pipeline / api / arch / docs 等门禁可本地复现。禁止只断言 HTTP 200，也禁止用 mock 模型冒充生产质量。

04

隐私与诚实

只梳理真实经历，不编造、不代答、不承诺 offer。未完成的删除、支付、OCR 与语音不会被写成可用服务。

Product path

一条练得完、看得懂的主路径

产品中心是面试准备，但停在一次聊天没有意义。目标闭环是：经历被整理、问题跟着你走、练完还能复盘。

真实经历

先锚定你写过的事实

简历与项目只作为练习素材。系统优化表达，不补造履历，也不帮人规避核验。

自适应面试

Agent 按回答追问

不是固定题单走完即停。文字主路径可暂停、可恢复；语音与图片 OCR 默认关闭，页面没有开放就不能用。

可复盘成长

反馈要能回头看

逐题点评和练习记录用于个人复盘，不构成能力认证，也不能当作招聘、资格或录用依据。

Interface

合成界面一览

截图文件位于 apps/web/docs/screenshots/，使用合成账号与合成记录。它们展示交互与视觉，不代表线上服务已开放，也不构成能力认证。截图里若出现「开始模拟面试」或「首次免费」，以当前文案与边界为准，不是现网承诺。

Current boundaries

当前能力边界

本页是项目导航与展示，不是已经部署的在线服务，不启动本地数据面服务，也不代理 API、认证、SSE 或任何用户数据。完整应用运行时仍在受控建设与验证中。

  • 不提供支付、购买、退款或自动扣费。
  • 完整删除、撤回同意与跨存储删除回执尚未开放。
  • 练习反馈不是用于招聘、资格或教育评价的数值评分。
  • 需要真实用户数据的 OCR、语音、长期记忆和跨会话召回不能称为已开放能力。
  • 请勿向任何预览环境提交真实简历、身份信息、录音、密钥或其他需要删除保证的内容。

README 里的边界与门禁说明 是同一套诚实口径。
