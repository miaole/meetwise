### 1.1 Column covered iff（NEG · FAULT · BOUND · ADV）

1. **Named NHP id(s)** registered in `non-happy-path-perf-load-case-matrix.md` for this UC + column（UC-018 anchors）:

   - **ADV** → **NHP-018-ADV-01**
2. **Dedicated prove CMD** EXIT=0 at a **committed SHA**（runner + script + package.json wire landed in that SHA · Ban uncommitted runner）.
3. **Post-prove dual receipts BOTH PASS**（`mw-e2e-ha` + `mw-rag-route`）citing that committed prove tip · **evidence of record = dual** · implementer-only receipts **≠** evidence of record.
4. **Real PG + PostgresSaver path**（cite `adr-postgres-retained.md`）· **Ban** MemorySaver · **Ban** MySQL · **Ban** Qdrant-as-required · **Ban** stub/fake checkpointer as covered evidence.
5. Column matrix §1.0 cell honestly reads **`covered`**（not `partial` / `case-only` / `blind`）**only after** a separate AUTHORIZED elevate knife with dual — **this COVERED-CRITERION knife never writes `covered` into matrix**.
