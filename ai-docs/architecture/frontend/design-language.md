# 设计语言与视觉规范

知面（Meetwise）的视觉系统。气质：**冷静、克制、可信，又有温度与鼓励**——像一位资深面试官在你答案旁认真批注。面向高压的求职场景，给人底气而非压力。

## 1. 设计原则（两条硬底线）

**A. 不要 AI 味（禁用清单）**：渐变文字/按钮、彩色发光阴影、hover 抬升、大圆角 bubbly、徽章 pill 滥用、emoji/✨、"AI 驱动"话术、居中通用 SaaS hero、字母塞进彩色圆角方块的图标。

**B. 不要装修/文艺味**：满屏衬线、土黄/土赭、印章、纸纹做主、mood-board 感。

**正向**：现代无衬线为主、克制留白、真实产品/数据前置（分数、能力条、批注）、人话文案、一抹克制的主色稀缺使用。温暖来自配色温度与文案语气，现代来自克制与真实。

## 2. Design Token（已定）

### 色彩
| token | 值 | 用途 |
| --- | --- | --- |
| `--c`（主色 朱红） | **#BE4030** | 强调、CTA、信号、批注 |
| `--c-d`（深） | #9E3325 | hover、深色上的强调 |
| `--c-soft` | #FAE6E1 | 浅底块（批注卡、pill、图标底） |
| `--c-em`（暗版强调） | #F0A99C | 深色 statement 上的强调字 |
| `--bg` | #FCF8F6 | 暖中性页面底 |
| `--ink` | #2A211F | 主文字 / 深色块 |
| `--ink2` | #5C504C | 次级文字 |
| `--hair` | #EFE5E1 | 发丝线 / 边框 |
| `--muted` | #988983 | 弱化文字 |
| 语义 | 低饱和 | success/warn/error 克制，不喧 |

主色**稀缺使用**——只用于强调、信号、批注，不铺满。

### 字体 / 字阶 / 间距 / 圆角 / 阴影
- 字体：`-apple-system / PingFang SC / Source Han Sans` 为主（现代无衬线）。**不满屏衬线**。
- 字阶：H1 52 / H2 30 / H3 17 / 正文 16 / 小 13–14；大标题字重 800、`letter-spacing:-1px`。
- 间距：8pt 栅格、大留白。
- 圆角：克制——卡片 14–16px、按钮 9–11px、小元素 4–8px；**不处处 2xl**。
- 阴影：仅产品/报告面用极轻软阴影做层级；**禁彩色发光**。

## 3. 核心组件（以 `home-11-red` 为准）

- **导航**：字标 + 几何方块标记（圆角方块 + 白点）+ 文字链 + 深色实心 CTA。
- **报告批注卡**：浅色头（评估中·主色脉冲点）→ 题/答 → **主色左边线的"点评"块** → 分数 + 能力条（主色/墨色）。这是签名组件。
- **能力条**：细条 + 主色填充；动效填入。
- **按钮**：主色实心（CTA）/ 白底描边（次级）；**无发光**。
- **stats / 能力卡**：hairline 边框卡片，悬停仅描边变主色（轻）。
- **deep statement**：墨色块 + 暗版强调字（`--c-em`）。

## 4. 动效系统（业务语义驱动）

**原则：动效服务业务语义，不做装饰。** 每个动效都对应一个产品时刻（批改 / 匹配 / 成长 / 评估），让动效本身在"演"产品价值，而不是炫技。曲线统一 `cubic-bezier(.2,.7,.2,1)`，无弹跳、无发光、无渐变闪烁。

### 招牌签名交互：红笔现场批改（canonical）
AI 像考官一样在你**真实回答**上：手写波浪线划重点 → 圈出漏点 → 引线写「点评」批注 → 描画分数环并计数。这是英雄区与报告页的核心 wow——独一份、契合批注红、把产品价值演在动效里。草图：`.tmp/brand/signature-markup.html`。

### 业务化动效词汇（每个绑定一个产品时刻）
| 动效 | 产品时刻 |
| --- | --- |
| **红笔批改**（划线/圈漏/写批注/分数环） | 评估 · 报告 |
| **简历×JD 匹配扫描**（高亮命中要求、标出差距） | 岗位匹配 · 简历诊断 |
| **能力曲线 / 雷达生长**（一节节长出来） | 成长档案 |
| **押题抽取**（从简历/题库"析出"问题 + 标考察点） | 押题 |
| **逐字成稿流式**（AI 边想边写） | 模拟面试对话 |
| **分数环描画** | 评分 |

### 两档强度
- **产品档（克制、稳）**：入场上浮淡入、发丝线 wipe、滚动揭示、链接下划线从左生长、CTA 箭头轻移。面试/报告/产品页用。
- **运营档（活力）**：侧滑入 + 轻微放大 + 数字蹦出 + hover 抬升。活动/海报/弹窗用，仍可控不廉价。
- 切换实验台：`.tmp/brand/motion-lab.html`。

### 无障碍
`prefers-reduced-motion` 下全部关闭：批注、分数、能力条直接呈现终态，内容不依赖动效可读。

## 5. 运营扩展层（C 端必备，从一开始预留）

两层系统、同一 token 基座：**核心品牌层**（产品/报告，克制可信）+ **运营表达层**（活动/促销/拉新/节日，更活力、可注入活动主色、海报感），但守住"真实/不打击/不夸大"底线。

预留组件：公告/活动栏、倒计时/限时、优惠券/红包、活动落地页模板、**裂变分享海报**（报告成绩 + 能力曲线 + 二维码）、角标、**节日主题换肤**（CSS 变量驱动，一处换活动主色）。

## 6. i18n 中的设计

中英双语：字体栈含中英；字阶/行高适配两种文字；运营/营销文案中英分别本地化（接 `frontend-blueprint` 的 i18n）。

## 7. 实现

- **shadcn/ui 当骨架，token 当皮**：把上述 token 写进 `packages/ui` 的 Tailwind config / CSS 变量，覆盖 shadcn 默认（zinc/默认圆角）。
- 签名组件（批注卡、流式渲染、能力条）自研；通用件用 shadcn。
- 主色与运营主题用 CSS 变量驱动，支持运营换肤。

## 8. LOGO

当前为几何方块标记（圆角方块 + 白点，主色）。最终需精修出 SVG + favicon + 深浅变体；可探索"知/面"字形或"对望/批注"概念。视觉草图见 `.tmp/brand/`（canonical：`home-11-red.html`、`style-board.html`），不进开源仓库。
