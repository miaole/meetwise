# 一、壁垒级能力(排序 + 一句为何)

先校正一个被五份评审反复打中的元判断:**本期(docs-first、零用户、Agent Architect 作品)没有已兑现的护城河,真壁垒全是未来时。本期纪律是"为飞轮埋好接缝 + 把唯一能讲 agent 深度的纵深做透",不是堆功能。** 排序如下:

1. **真实结果回流 → 纵向能力曲线 → 评估校准飞轮**(Outcome capture)。全清单唯一难抄的资产:竞品能抄题/卡/匹配分,抄不走"真实作答×真实 offer 结果"的校准数据。**但有幸存者偏差(挂了的人不回标)、因果不可识别、稀疏延迟三个硬伤——本期只静默埋点,定位为长期 telemetry / ai-eval 弱信号,绝不承诺它本期能校准评分或喂教练。**
2. **War Room 多图编排**(登记真实面试日期/JD → career-path+resume-quiz+mock-interview 三图协同产出"今日定向任务" → 评估输出回流)。绑真实求职生命周期 + JD 定向,是唯一同时拉满"高意图窗口每日回访 + 高付费意愿 + 多图编排可辩护"的切片;这是 Agent Architect 真正想看的东西。
3. **评估数据沉淀成个性化 SRS**(错题 → ReviewItem 状态机,复用已有双校验评估输出,零新增 AI 成本)。集内个性化、越用越准。**诚实降级:这是弱飞轮(episodic 数据量撑不起跨年个性化),壁垒在集内而非跨集,别当主梁叙事。**
4. **教练-评分中立隔离 + fact-only 可审计记忆**(独立 subgraph、独立记忆命名空间、对分数/权益零写权限)。这是质量地板 + 面试可辩护核心(竞品把教练和评委做成一个 prompt 的两副语气,必谄媚或污染),**但用户无感知,是信任底座不是增长资产**。
5. **公司/岗位能力资产**(远期)。语料 + 结果飞轮是唯一能从"练习引擎"长成"求职结果产品"的护城河,**但本期是内容负债伪装成壁垒**(无规模、无回标、半年馊、语料正当性红线),只手工 1–2 个顶流岗位包当营销素材,禁挂"飞轮"叙事。

# 三、MVP 切(本期 C 端增厚最小集,窄而深)

**一条主纵深 + 两个低成本附件,全部是图变体或确定性业务逻辑,零新编排图、零新基建:**

**主刀(offer-targeting,展示多图编排):**
- JD 结构化(resume 摄取管线 + 抽取子步骤,JD 入 data block + 双校验)
- 简历×JD 匹配分 + 可解释差距(career-path 的 JD 条件化变体)——**必须带不确定性护栏**
- JD 定向押题(resume-quiz 加 `jobPostingId`,每题映射真实 JD 需求项,可重复扣额度=变现主体)
- War Room 轻量版(手填面试日期 → 自动排倒计时每日任务,**点了再生成,不预生成**)
- Outcome 仅静默埋点(三态 `unknown/offer/rejected`,脱敏不入 B 端线)

**附件 1(retention,集内回路):** 错题 → ReviewItem SRS-lite(SM-2/固定桶,确定性业务逻辑、绝不进 LangGraph),微练习作为执行单元复用,不独立立项。

**附件 2(ai-coach,信任+变现楔子):** 教练-评分中立隔离(day-1 规则)+ 面后复盘+感谢信(校验拦"捏造+拔高")+ fact-only 记忆。谈薪薄版(复用 mock 拓扑,无需 comp DB)作为唯一能自证变现的楔子,可并入或紧随。

**Schema day-1 必预留(零成本,后期补不上):** 求职窗口/上岸标记字段、Outcome 关联练习记录、SRS 难度参数字段 + k≥20 聚合下限、private→global 搬运的 consent/status 位、教练记忆"用户可见/可删"。

**横切硬约束:** 免费/匿名 AI 路径必须有成本封顶(限流 + 单设备/IP 上限);免费层每日微练习 1 题封顶,SRS 复习/War Room 定向押题/匹配深度进付费墙。

# 四、坚决不做 / 暂不做(各一句理由)

**坚决不做:**
- 视频面试 / face landmark / 微表情——PIPL 生物识别风险 + 移动前摄眼神指标物理失真 + 伪科学。
- 真代码执行沙箱——跑陌生人代码是全产品最高运维 liability(逃逸/挖矿/成本失控),个人项目不该运营。
- 1v1 真人 marketplace / 内推撮合——双边供给 + 合规悬崖,且内推踩 B 端隔离线。
- streak 整套(段位/freeze 卡/损失厌恶推送)——高压求职人群用焦虑驱动留存是伦理红线 + 伤品牌 tone。
- 邀请返点 / 算力补贴拉新——用真金算力补贴 = 负毛利且无封顶,被薅穿。
- 多档订阅矩阵 / 公开 UGC 社区 + 人工审核台——冷启动无人力无规模,纯 B 端中台思维。

**暂不做(留接缝):**
- 公司付费包——语料正当性门禁未过 + 无规模,本期是空壳。
- 跨窗口召回 / 长期陪伴问责——分集式需求,跨年钩子是幻觉;数据字段先留。
- 公开面经 feed / 榜单 / PK——核心留存未验证前,社交是放大器不是引擎。
- 白板画布 / 群面多 persona——移动反人类 / portfolio 驱动,可时间盒做但不计入留存账。

# 五、留存 × 变现一句话主张

**增厚后 C 端 = 以"真实面试日期/JD"为外部 deadline 锚点的 War Room 把高意图窗口内的每日定向陪练(可重复扣额度)做成回访引擎,用错题 SRS 兜集内复习、用面后复盘+感谢信接住真实面试当下、用脱敏战绩海报做唯一裂变载体;收入压在"冲刺季 Pass(时间盒订阅,匹配求职真实使用曲线)+ 可重复练习扣费 + AI 深档/谈薪单次加购",匹配分免费当转化钩子、能力曲线历史永远免费(只对前瞻处方收费),从"用完即走的练习器"变成"对着真实岗位陪你练到 offer 的诚实消费品"——而真护城河(结果回流校准飞轮、岗位能力资产)是规模后的二阶下注,本期只埋接缝、不假装拥有。**

# 六、待你拍板的产品决策

1. **主纵深确认**:本期是否锁定 offer-targeting(War Room)为唯一主刀?(评审一致认为这是唯一能同时讲 agent 故事 + 扛留存 + 接变现的切片;若你更想押 retention 或 coach 主线,排序要重来。)
2. **匹配分形态**:接受把匹配分定位为"免费转化钩子 + 带不确定性护栏的区间+证据"、收入压在定向练习,而非把匹配分当核心付费点?(涉及定价结构 + 业务校验器新增"禁伪定论"验收项。)
3. **订阅 SKU**:主力订阅是否就用"求职冲刺 Pass"(30 天时间盒、不自动转长约)+ Free/Pro 两档,拒绝多档矩阵?(接受其 MRR 低、lumpy、复购靠下次求职的代价。)
4. **谈薪楔子优先级**:薄版谈薪(无 comp DB)是否提到 MVP 第一批付费实验,而非压到深水区?(它是教练层唯一清晰的钱。)
5. **Outcome 埋点定位**:确认本期只做静默采集、明确不承诺任何下游校准/喂教练?(防止把三年后才能证伪的指标写进本期成功判据。)
6. **匿名首跳**:E1 免登录评分是否砍掉 anon→user 的 checkpoint merge(改登录后重跑 + anon checkpoint TTL 即焚),以规避跨身份隐私缝?
7. **两条新红线入 rules**:是否把"不可用焦虑驱动留存(衰减分/濒断文案对外不得渲染下跌恐慌)"和"匹配分/公司包语料正当性门禁"写进 `ai-docs/rules`?(增长侧一定会滑过去,需机制级拦截。)
