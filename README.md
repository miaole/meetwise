# Meetwise · 知面

> 围绕真实经历进行表达练习、模拟面试与个人复盘的项目预览。

Meetwise 帮助求职者把自己已经做过的事说得更清楚：整理简历、练习问题、完成多轮文字面试，并查看本次练习的反馈。它不提供编造经历、夸大资历、代答或规避核验的能力，也不承诺面试、录用或 offer 结果。

## 公开边界

这是代码与产品界面的预览，不是已经部署的在线服务。页面、源码和文档会区分以下状态：

| 状态 | 含义 |
| --- | --- |
| 代码基础 | 仓库中已有实现或接口基础，但不等于线上可用。 |
| 默认关闭 | 能力保留在代码中，尚未满足安全、成本、删除或验收条件。 |
| 规划中 | 有设计与测试计划，尚未接入用户路径。 |
| 发布阻断 | 在完成真实环境验证前，不对用户作可用性或合规承诺。 |

当前发布阻断项包括：完整数据删除与撤回、云端数据面执行、统一模型操作治理、评分校准、长时记忆与跨会话召回。具体状态以仓库中的运行时事实说明为准。

## 可以看到什么

- 围绕用户主动提供内容的简历练习与结构化提取基础。
- 文字模拟面试、逐题反馈和练习报告的代码路径。
- 输入校验、访问隔离、状态机与故障降级等工程基础。
- 招聘流程中的最小状态展示与人工复核边界；不展示数值招聘评分，也不执行自动筛选、排名、拒绝或录用决定。

模型生成的反馈只用于个人练习和复盘。它不是经校准的能力认证，也不能用作招聘、资格、教育评价或其他高影响决定的依据。

## 暂不对外开放

- 支付、购买、退款和自动扣费服务。
- 完整删除、撤回同意、外部处理方回执以及跨存储的删除证明。
- 视觉 OCR、语音、embedding、rerank 与流式模型能力的统一治理路径。
- 长时专家面试、跨会话语义记忆、自动岗位路由和桶内生成题的完整闭环。
- 云端 ECS 执行器、真实数据面 E2E 和发布级性能证明。

因此，请不要向预览环境提交真实简历、真实身份信息、录音、密钥或其他需要删除保证的内容。

## 仓库结构

```text
apps/
  web/        Next.js App Router 页面与同源代理
  api/        NestJS API、鉴权与应用服务
  worker/     异步任务、面试编排与受控后台处理
packages/
  contracts/  共享输入输出契约
  domain/     纯领域规则与状态机
  db/         迁移、约束、RLS 与数据库访问层
  ai-runtime/ 模型适配与调用控制基础
  ai-graphs/  图编排定义
ai-docs/      产品、架构、用例、测试与运行时事实说明
  preview-site/ 由 GitHub Pages 发布的静态引导页；主应用入口仍会在受验证的预览发布后启用
```

## 文案与安全原则

- 只协助梳理真实经历，不编造、不夸大、不代答。
- 练习反馈不等于能力认证，不能用于自动招聘决策。
- 未完成完整删除闭环前，不把删除或撤回描述为可用服务。
- 不把本地验证、静态检查或设计文档描述成发布证据。
- 不提交真实密钥、真实简历、录音或其他敏感资料。

## 可运行的静态检查

以下命令不启动本地数据面服务，也不读取云端密钥：

```bash
corepack pnpm docs:check
corepack pnpm public-text-policy:prove
corepack pnpm -C apps/web prove:public-copy
```

静态检查只能证明当前文本、契约或代码结构满足对应规则；它们不等同于真实云端运行、隐私删除或发布验收。
